### Проект 'What to watch'

Веб-приложение на Flask, которое показывает случайные мнения о фильмах и позволяет добавлять собственные.

## Функционал:

- Отображает случайное мнение о фильме-.

- Позволяет получить другое мнение по кнопке «Хочу другой фильм» или обновлением страницы.

- Генерирует уникальные ссылки для каждого фильма, которыми можно делиться.

- Поддерживает добавление собственных фильмов и отзывов через форму.

## Стек технологий:

- Python, Flask, Flask-WTF, Flask-SQLAlchemy, SQLite, Jinja2

## Как запустить проект:

Клонировать репозиторий и перейти в него в командной строке:

```
git clone 
```

```
cd what_to_watch
```

Cоздать и активировать виртуальное окружение:

```
python3 -m venv venv
```

```
source venv/bin/activate
```
или для пользователей Windows

```
source env/Scripts/activate
```

Установить зависимости из файла requirements.txt:

```
python3 -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

Запустить проект:

```
flask run
```
